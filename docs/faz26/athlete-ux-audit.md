# FAZ 26 — Sporcu UX Audit

## Kritik

| Sorun | Konum | FAZ 26 aksiyonu |
|--------|--------|------------------|
| Dekoratif büyük CTA kartları | Sabah / finans blokları | `CompactActionCard` / `CompactFinanceCard` |
| Zayıf empty state | Kütle grafiği, yoklama | `AthleteEmptyState` yönlendirici metin |
| Radar çok yüksek | Gelişim profilim | `PerformanceRadar` 180–200px |

## Orta

| Sorun | Konum | FAZ 26 aksiyonu |
|--------|--------|------------------|
| Yoklama listesi kalabalık | Yoklama özeti | `CompactTimelineItem` |
| Boy/kilo kartları büyük | Profil sidebar | `AthleteMetricCard` kompakt |
| Program kartı hero boyutunda | Grid | `CompactActionCard` |

## Düşük

| Sorun | Konum | Not |
|--------|--------|-----|
| Email overflow | Profil | `truncate` + `title` korundu |
| RPE strip mobilde | Quick strip | FAZ 23’te mevcut |
